# MUKHTABAR — المختبر

مختبر علمي تفاعلي باللغة العربية، مصمم للهاتف وTelegram Mini Apps.

## الموجود في المختبر

- واجهة عربية RTL متجاوبة مع تصميم مخصص للهاتف.
- محاكاة ثلاثية الأبعاد تعليمية لمراحل الانقسام المتساوي.
- مدارات كوكبية محسوبة عددياً، مع مسار مداري متوقع، ونجم وكوكب بخامات إجرائية وسحب وغلاف جوي.
- محاكاة حركة المقذوفات مع تغيير زاوية الإطلاق والسرعة والجاذبية والارتفاع.
- محرك تجارب مولّدة من وصف المستخدم، يستخدم مواصفات JSON آمنة بدلاً من تنفيذ JavaScript صادر من النموذج.
- أنواع المحاكاة المولّدة حالياً: توكاماك توضيحي للبلازما والمجال المغناطيسي، موجات جيبية متحركة، بندول ديناميكي، ومشاهد ثلاثية الأبعاد عامة بعناصر وحركات قابلة للضبط.
- أدوات تحكم عددية وقراءات وشرح علمي لكل تجربة مولّدة.
- مكتبة محلية لحفظ التجارب المولّدة والحالية وإعادة فتحها وتصديرها واستيرادها.
- حفظ عبر IndexedDB مع بديل localStorage، ودعم أولي لـ Telegram WebApp SDK.

## كيف يعمل توليد التجارب

يرسل المتصفح وصف المستخدم إلى Cloudflare Worker. يطلب النظام من Gemini إما اختيار محاكاة موجودة أو إنشاء مواصفات ضمن مخطط mukhtabar-sim-v1. يتحقق محرك simulation-engine.js من أنواع العناصر والحركات والمدخلات والمدى المسموح للقيم، ثم يبني المشهد باستخدام Three.js.

النموذج لا يرسل JavaScript قابلاً للتنفيذ، ولا يستطيع إضافة شيفرة عشوائية إلى الصفحة. أنواع الحركة والفيزياء المتاحة هي قدرات المحرك الفعلية؛ لذلك تظل بعض الظواهر نماذج تعليمية توضيحية وليست محاكاة هندسية أو بحثية كاملة. يشرح كل نموذج افتراضاته وحدوده بدلاً من ادعاء دقة غير موجودة.

## إعداد الذكاء الاصطناعي

1. افتح Cloudflare Workers & Pages واختر Worker باسم aaa.
2. أضف GEMINI_API_KEY كـ Secret في إعدادات Worker.
3. لا تضع المفتاح داخل ملفات HTML أو JavaScript العامة أو GitHub.
4. عنوان الخدمة المستخدم في ai-config.js هو https://aaa.lkg75589.workers.dev/chat.

راجع AI_SETUP.md للتفاصيل.

## النشر والفحص

- index.html هو التطبيق الرئيسي.
- simulation-engine.js هو محرك المحاكاة المولّدة.
- ai-worker/worker.js هو وسيط Gemini الخلفي.
- GitHub Actions يفحص HTML وJavaScript وملفات إعداد Worker عند الدفع إلى main.
- GitHub Pages ينشر ملفات الواجهة تلقائياً.
