# MUKHTABAR — المختبر

مختبر علمي تفاعلي باللغة العربية، مصمم للهاتف وTelegram Mini Apps.

## الميزات الموجودة
- واجهة عربية RTL متجاوبة.
- محاكاة ثلاثية الأبعاد تعليمية لمراحل الانقسام المتساوي.
- مشهد ثلاثي الأبعاد لمدار كوكبي مع تحكم بإيقاف الحركة ومتابعتها.
- محاكاة حركة المقذوفات مع تعديل زاوية الإطلاق والسرعة الابتدائية وتعجيل الجاذبية.
- مكتبة محلية لحفظ التجارب وإعادة فتحها وإعادة تسميتها وحذفها.
- حفظ أساسي عبر IndexedDB مع بديل عبر localStorage عند تعذر IndexedDB.
- دعم أولي لـ Telegram WebApp SDK.

## حدود وضع الإنشاء الحالي
إنشاء التجارب يعمل حالياً بوضع تجريبي يطابق وصف المستخدم مع واحد من ثلاثة محركات محاكاة جاهزة. هذا ليس توليداً مفتوحاً لتجارب جديدة بالذكاء الاصطناعي.

لتفعيل التوليد الحقيقي، يلزم إعداد خدمة خلفية آمنة مثل Cloudflare Worker وربطها بعنوان الخدمة في متغير `API_URL`. لا تضع مفاتيح API داخل ملفات HTML/JS العامة أو في GitHub.

## النشر
يوجد سير عمل GitHub Actions في `.github/workflows/pages.yml`:
- يفحص بنية HTML وتكرار المعرّفات وصياغة JavaScript عند فتح Pull Request أو الدفع إلى `main`.
- ينشر GitHub Pages تلقائياً بعد الدفع إلى `main`.

لأول نشر، افتح **Settings → Pages** في المستودع واختر **GitHub Actions** كمصدر النشر.
