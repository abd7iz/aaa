# MUKHTABAR — المختبر

مختبر علمي تفاعلي باللغة العربية، مصمم للهاتف وTelegram Mini Apps.

## الميزات الحالية
- واجهة عربية RTL متجاوبة.
- محاكاة تعليمية ثلاثية الأبعاد لمراحل الانقسام المتساوي.
- محاكاة حركة المقذوفات مع تغيير زاوية الإطلاق.
- مشهد ثلاثي الأبعاد لمدار كوكبي.
- حفظ التجارب محلياً في IndexedDB على الجهاز والمتصفح نفسه.
- تكامل أولي مع Telegram WebApp SDK.

## وضع الذكاء الاصطناعي
إنشاء التجربة يعمل حالياً بوضع تجريبي يختار أقرب محاكاة جاهزة من وصف المستخدم. لا يوجد توليد مفتوح لمحاكاة جديدة بواسطة نموذج ذكاء اصطناعي حتى يتم إعداد خدمة خلفية آمنة.

لا تضع مفاتيح API داخل HTML أو JavaScript المنشور علناً. استخدم خدمة خلفية مثل Cloudflare Worker وخزّن المفاتيح ضمن Secrets.

## النشر على GitHub Pages
يجب أن يكون `index.html` في جذر المستودع. من إعدادات المستودع افتح **Settings → Pages** واختر مصدر النشر المناسب. بعد اكتمال النشر يكون الرابط المتوقع:
https://abd7iz.github.io/aaa/
