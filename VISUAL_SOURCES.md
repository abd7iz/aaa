# MUKHTABAR — Visual sources and attribution

## Earth surface and cloud maps

The interactive orbit scene loads these texture maps from the public
[solar-system-viz repository](https://github.com/JiayuanZhu/solar-system-viz):

- `2k_earth_daymap.jpg` — Earth daytime surface map.
- `2k_earth_clouds.jpg` — Earth cloud layer.

The repository README attributes these texture assets to
[Solar System Scope](https://www.solarsystemscope.com/textures/), licensed
under **Creative Commons Attribution 4.0 International (CC BY 4.0)**.

Attribution: **Solar System Scope — Earth texture maps, CC BY 4.0**.
License: https://creativecommons.org/licenses/by/4.0/

The MUKHTABAR scene uses Three.js for rendering, with independently written
scene, camera, lighting, geometry, animation and experiment-control code.

## Biological visualization references

The following public repositories were reviewed as technical references for
interactive cell visualization:

- https://github.com/QI-flowy/3DArchitectureStudio
- https://github.com/bexonia/learn-biology

No GLB model files or source-code blocks from these repositories were copied
into MUKHTABAR. This avoids redistributing specimen assets whose individual
licenses or provenance may differ from the repository's code license.

The cell scene in MUKHTABAR is assembled from original Three.js geometry and
materials. It is an educational schematic visualization, not a microscopy
image or a claim of exact molecular-scale proportions.
